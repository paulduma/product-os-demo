# Level 4 — Operator

**Goal: install your own OS.**

> Roadmap : [index](README.md) · Niveau 4/5 · Précédent → [Level 3 — Shipper](03-shipper.md) · Suivant → [Level 5 — Director](05-director.md)

---

## What to do

Stop treating this as a tool you occasionally reach for. Set up your own Product OS — skills, a `CLAUDE.md`, a project template — on your machine, and make it the way you start every project from now on. This is the level where it stops being a novelty and starts being infrastructure.

## You're done with this level when

Starting a new project without your OS feels like it's missing something.
